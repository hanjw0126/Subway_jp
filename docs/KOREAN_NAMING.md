# 역명 한글 표기

우선순위: **① ODPT 한국어 표기(`odpt:stationTitle.ko`) → ② `tools/seed/ko_overrides.csv` → ③ 가나 자동 변환**

자동 변환 규칙(국립국어원 외래어 표기법 일본어 기준):
- 어두의 か·た행은 예사소리(가, 다), 어중은 거센소리(카, 타). 예: きょうばし → 교바시
- つ → 쓰, ん → ㄴ받침, っ → ㅅ받침. 예: いっちょうめ → 잇초메
- 장음(ー, おう, うう 등)은 적지 않음. 예: とうきょう → 도쿄

보정이 필요한 예: 広尾(ひろお) → 자동 "히로" → 보정 "히로오".
수정 제보는 이슈 템플릿 **역명 한글 표기 수정**을 이용하거나 `ko_overrides.csv`에 한 줄 추가해 PR을 보내주세요.

## 한국어 위키백과 표기 병기 (`koAlt`)

앱 표기와 한국어 위키백과(위키데이터) 표기가 다르면 `network.json` 의 `name.koAlt` 에 위키백과 표기를 넣는다.

- 수집: `python tools/ko_wiki.py` → `tools/seed/ko_wiki.json` (위키데이터 SPARQL, CC0). Rebuild maps 워크플로가 실행할 때마다 다시 받고, 실패하면 기존 파일을 그대로 쓴다.
- 대응: 같은 일본어 역명(駅·괄호 제외)이면서 2 km 이내인 가장 가까운 항목. 띄어쓰기·가운뎃점 차이는 같은 표기로 본다.
- 표시: 역명 언어가 한국어일 때 **역 상세정보 제목**과 **역 검색 결과**에 `앱 표기 (위키백과 표기)` 로 보여 준다. 노선도에는 표시하지 않는다.
- 검색: 위키백과 표기(초성 포함)로도 찾을 수 있다.
