# 노선도 설계

공식 노선도를 따라 그리지 않고 **역 좌표에서 자동 생성**합니다(저작권 회피 + 일관성).

1. 위경도 → 평면 좌표(지역 중심 기준 등거리 투영, 지역에 따라 도심을 넓히는 방사 압축 — `tools/geo_projection.py`).
2. 각 구간 방향을 0°/45°/90°… 8방향으로 스냅, 역 간격을 균일화.
3. 환승역 그룹은 한 점으로 합치고, 같은 구간을 여러 노선이 지나면 평행선으로 오프셋.
4. 역명 라벨 위치(8방향 후보)를 선과 겹치지 않게 선택.
5. 결과 `layout.json`: 역별 `x, y, labelDir`, 노선별 경로. 앱은 `SubwayMapCanvas`에서 그대로 그립니다.

## 반드시 지키는 조건 (모든 나라 노선도 공통)

노선도 생성기(`tools/layout_schematic.py`)의 충돌 복구가 아래 위반을 없앨 때까지 역을 옮기고,
테스트(`tools/tests/test_layout.py`)가 지역마다 0 인지 검사합니다.

| 지표 | 뜻 |
|---|---|
| `selfCrossings` | **같은 노선**의 두 구간이 서로 교차 (노선이 꼬임, 예: 3호선 대치–가락시장이 스스로 엇갈림) |
| `overlaps` | 서로 다른 구간이 같은 직선 위에서 포개짐 (평행선 다발로 그리는 경우는 `bundled` 로 따로 셈) |
| `nodeOnEdge` | 노선이 정차하지 않는 역 위를 지나감 |

서로 **다른 노선끼리** 교차하는 것(`crossings`)은 실제 노선망에서도 피할 수 없어 가벼운 비용으로만 줄입니다.

노선도를 다시 만들 때마다 지역별 지표와 위반 위치(노선·역 이름)가 `docs/images/layout_report.md` 에 기록되고,
검증이 실패하면 출력이 `docs/images/validate_log.txt` 에 남습니다.

## 노선 추가
1. `tools/seed/<지역>.json`에 역(ODPT ID, 좌표, 번호)을 추가하거나 `fetch_odpt.py`로 받습니다.
2. `python tools/build_all.py --region <지역>` 실행.
3. `docs/images/map_<지역>.png` 미리보기를 확인해 PR에 첨부합니다.

## 시인성 규칙
- 선 두께 6dp, 환승역은 흰 원 + 검은 테두리, 일반역은 노선색 테두리.
- 글자는 확대 배율과 무관하게 12sp 고정, 흰 배경을 깔아 선 위에서도 읽히게 합니다.
- 노선색은 각 사업자 공식 라인 컬러(공개 정보)를 사용합니다.
