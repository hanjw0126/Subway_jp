# 경로 탐색 (RAPTOR)

- 같은 정차 패턴의 열차를 하나의 Route로 묶고, 라운드 k = k번째 탑승으로 반복합니다.
- 각 라운드의 목적지 도착 시각 중 개선된 것만 남기면 **(도착시각, 환승횟수) 파레토 최적 해**가 나옵니다.
  - 가장 늦은 라운드 해 = **최단시간**, 가장 이른 라운드 해 = **최소환승**.
- 환승: 같은 역 그룹 내 도보 시간(`transfers.walkSec`, 기본 180초) + 최소 환승 여유 60초.
- `searchAlternatives`: 첫 해의 출발 시각 +1초로 재탐색해 다음 열차 대안을 모읍니다.
- 출발역·도착역은 역 그룹(환승역의 모든 노선 플랫폼)으로 확장해 검색합니다.
- 막차 이후에는 결과가 없으며, UI가 "오늘 운행 종료"를 안내합니다.
