# "N분 후 도착" 계산

1. 오늘의 운행일과 요일 구분(평일 / 토요일 / 휴일)을 구합니다. 일본 공휴일, 대체휴일, 연말연시(12/30~1/3)는 휴일 시간표.
2. 해당 역·방면을 지나는 열차(`Trip`)의 정차 시각을 찾습니다. 이 역이 종착인 열차는 제외합니다.
3. 실시간 `odpt:Train`에서 같은 열차번호의 `delay`(초)를 더합니다: **예측 도착 = 시간표 도착 + 지연**.
4. 열차 위치 판정
   - 실시간 있음: `fromStation`/`toStation`으로 판단. 전역에 정차 중이면 "전역 도착", 전역→이 역 이동 중이면 "전역 출발", 60초 이내면 "곧 도착".
   - 실시간 없음: 시간표와 지연값만으로 현재 위치를 추정하고 카드에 "시간표 기준"으로 표시.
5. 분 = 올림((예측 도착 − 현재) / 60). 0 이하는 "곧 도착". 방면별로 가까운 2대를 보여줍니다.
6. 운행 중단 등 `odpt:TrainInformation` 이상 상태면 카드 위에 경고 배너를 표시합니다(`StatusTranslator`로 한국어 요약).

한계: ODPT가 실시간 위치를 제공하지 않는 사업자는 시간표 기준으로만 표시됩니다. 직통운전으로 다른 회사 노선에서 들어오는 열차는 위치를 "운행 중"으로만 표시합니다.
