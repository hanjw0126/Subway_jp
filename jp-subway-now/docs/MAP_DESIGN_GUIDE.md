# 노선도 설계

공식 노선도를 따라 그리지 않고 **역 좌표에서 자동 생성**합니다(저작권 회피 + 일관성).

1. 위경도 → 평면 좌표(지역 중심 기준 등거리 투영).
2. 각 구간 방향을 0°/45°/90°… 8방향으로 스냅, 역 간격을 균일화.
3. 환승역 그룹은 한 점으로 합치고, 같은 구간을 여러 노선이 지나면 평행선으로 오프셋.
4. 역명 라벨 위치(8방향 후보)를 선과 겹치지 않게 선택.
5. 결과 `layout.json`: 역별 `x, y, labelDir`, 노선별 경로. 앱은 `SubwayMapCanvas`에서 그대로 그립니다.

## 노선 추가
1. `tools/seed/<지역>.json`에 역(ODPT ID, 좌표, 번호)을 추가하거나 `fetch_odpt.py`로 받습니다.
2. `python tools/build_all.py --region <지역>` 실행.
3. `docs/images/map_<지역>.png` 미리보기를 확인해 PR에 첨부합니다.

## 시인성 규칙
- 선 두께 6dp, 환승역은 흰 원 + 검은 테두리, 일반역은 노선색 테두리.
- 글자는 확대 배율과 무관하게 12sp 고정, 흰 배경을 깔아 선 위에서도 읽히게 합니다.
- 노선색은 각 사업자 공식 라인 컬러(공개 정보)를 사용합니다.
